安装 Codex Co²

共享一条 Codex 会话，一起推进工作。

  1. 将 Codex Co² 拖入安装盘中的 Applications。
  2. 从“应用程序”文件夹打开 Codex Co²。

如果提示“未打开 Codex Co²”

此实验预览包尚未经过 Apple 开发者身份签名和公证。仅在你确认安装包来源可信时，按以下步骤为这个应用放行。

  1. 在系统拦截提示中点击“完成”。
  2. 点击下方按钮打开“隐私与安全性”，向下找到“安全性”。
  3. 在 Codex Co² 的拦截说明旁点击“仍要打开”，按系统提示完成验证，再确认“打开”。

打开隐私与安全性

也可双击安装盘里的“打开隐私与安全性”快捷入口。快捷入口只打开设置页面；“仍要打开”和身份验证需由你亲自完成。

如未出现按钮，请先再次尝试打开 Codex Co²，再回到此设置页。页面位置随 macOS 版本有所不同；快捷入口无效时，请手动前往“系统设置 → 隐私与安全性”。受管理的 Mac 请联系管理员。

查看 Apple 官方说明

Experimental project · 实验性项目

This experimental package is ad-hoc signed and not notarized by Apple. Install only from a trusted project release. Drag the app into Applications; if blocked, review Apple’s instructions before approving it in Privacy & Security. Stop sharing, disable background running if enabled, then quit the previous Co² app before updating. Keep official Codex Desktop running. Native tool approval and clean-Mac download/install acceptance remain unverified.

开始协作

保持官方 Codex Desktop 运行，再打开 Codex Co²，选择要共享的会话。
