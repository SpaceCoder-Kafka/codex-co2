What it is

Multiplayer for Codex.

How it works →

Screen sharing lets people watch. Copy-pasting a chat loses the live context. Co² puts your team in the same Codex conversation, with the same agent.

Pick one conversation in Codex Desktop and send an invitation. Teammates follow the history and new replies in their browser and add context or the next instruction themselves. The agent keeps running on your machine, and you stay in control of who joins and what runs.

How it works

One conversation, three ends.

01Host

Official Codex Desktop

Keeps running on your Mac or PC, unmodified. Co² never restarts, patches or replaces it, and stops if its interface is unavailable.

02Bridge

Co² host app

Attaches to Desktop's existing local interface and shares only the conversation you pick, through an outbound TLS relay or an intranet-only link.

03Guests

Any browser

Teammates open the invitation, wait for your approval, then message the same agent. Nothing to install, no Codex login.

Security at a glance

Sharing an agent means sharing what it can do.

Read this before you invite anyone.

  • Same agent, same permissions.Guest messages use the conversation's existing tools, sandbox and usage allowance. Invite only people you trust.
  • One conversation only.Your other conversations and Codex credentials are never shared.
  • You stay in control.You approve each guest, can require approval for every message, and can revoke access at any time. Tool approvals stay in Desktop.
  • Not end-to-end encrypted.Public sharing relies on TLS and the relay. Intranet-only mode uses plain HTTP on your private network.
  • Revoking stops new delivery.It can't erase what a guest already copied.

FAQ

Questions.

01Can I share a Codex conversation with my team?

Yes. Co² shares one conversation from the official Codex Desktop app on your computer. Invited teammates see its history and live replies in a browser and can send messages to the same agent.

02Do collaborators need Codex or an OpenAI account?

No. Guests only need a modern browser. The agent runs on the host's computer under the host's Codex setup, so guest messages use the host's tools, sandbox and usage allowance.

03Can a teammate continue the work on their own computer?

Yes. With Co² installed, a guest can choose Import to my Codex to create an independent copy of the conversation in their own Codex Desktop.

04Is it end-to-end encrypted?

No. Public sharing goes through an outbound relay protected by ordinary TLS. Intranet-only mode uses plain HTTP on a private network you select and never falls back to a public link.

05Is Codex Co² an official OpenAI product?

No. It is an independent, experimental open-source project. It is not affiliated with or endorsed by OpenAI.
