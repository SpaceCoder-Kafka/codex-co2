工作原理

一条会话，三个端。

01分享者

官方 Codex Desktop

在你的 Mac 或 PC 上照常运行，不做修改。Co² 不会重启、修改或替换它；Desktop 接口不可用时会直接停止。

02桥接

Co² 主机应用

连接 Desktop 现有的本地接口，只共享你选中的那条会话，经出站 TLS 中继或仅内网链接送达协作者。

03协作者

任意浏览器

同事打开邀请、等你批准后，就能给同一个 Agent 发消息。无需安装，无需登录 Codex。

演示视频

运营、研发、产品，在同一条会话里接力解决一条用户反馈。

安全要点

共享 Agent，就是共享它能做的事。

邀请任何人之前，请先读完这几条。

  • 同一个 Agent，同样的权限。协作者的消息会使用这条会话现有的工具、沙箱和额度。只邀请你信任的人。
  • 只共享一条会话。你的其他会话和 Codex 凭据不会被共享。
  • 控制权在你手里。你逐个批准协作者，可以要求每条消息先经你审批，也可以随时撤销访问。工具审批仍留在 Desktop。
  • 不是端到端加密。公网分享依赖 TLS 和中继；仅内网模式在你的私有网络上使用未加密的 HTTP。
  • 撤销只会停止后续投递。它无法抹去协作者已经复制的内容。

常见问题

常见问题。

01Codex 会话可以分享给团队一起用吗？

可以。Co² 从你电脑上的官方 Codex Desktop 共享一条会话。受邀同事在浏览器里看到历史和实时回复，并能给同一个 Agent 发消息。

02协作者需要安装 Codex 或拥有 OpenAI 账号吗？

不需要，只要一个现代浏览器。Agent 运行在分享者电脑上、使用分享者的 Codex 配置，所以协作者的消息会使用分享者的工具、沙箱和额度。

03同事能在自己电脑上接着做吗？

可以。协作者安装 Co² 后，可以选择「导入到我的 Codex」，在自己的 Codex Desktop 中得到一份独立副本。

04是端到端加密的吗？

不是。公网分享通过出站中继，依赖普通 TLS。仅内网模式在你选择的私有网络上使用未加密的 HTTP，并且不会回退到公网链接。

05Codex Co² 是 OpenAI 官方产品吗？

不是。这是一个独立的实验性开源项目，与 OpenAI 没有隶属或背书关系。
