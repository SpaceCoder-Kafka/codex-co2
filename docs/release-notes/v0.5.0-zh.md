# Codex Co² 0.5.0

[English →](../../CHANGELOG.md#050)

**新功能**

1. **把共享会话导入自己的 Codex。** 访客获准加入后，可选择「导入到我的 Codex」，在本机 Co² 确认后即可在 Desktop 中打开独立会话。分享端和接收端均支持附件导入时，副本会在原消息中保留已下载原件的本地链接，也支持纯附件消息。导入时会标明缺失文件和被截短的历史。

   - **接手同事查到一半的 Bug。** 同事已经记下了复现步骤，也排除了几个原因。接手时导入这段对话，直接问 Codex「根据刚才的结果，下一步该做哪个验证？」
   - **从同一个问题出发，试另一条路。** 团队在共享会话里讨论一次性迁移，你可以在自己的副本里问「沿用刚才的兼容性要求，分批迁移该怎么做？」这些追问只出现在你的会话里，等两份方案成形后再一起比较。
   - **把设计评审变成验收清单。** 在分享结束前导入评审讨论和随附的设计稿。第二天，即使共享已结束，你仍能打开已保存的设计稿，对照会上敲定的细节，让 Codex 帮你逐页列出验收项。

2. **回到原来的内网会话。** 启用恢复记录后，主机重启时可恢复符合条件的分享。macOS 分享者更换内网地址后，访客通过 Bonjour 邀请在原浏览器打开会话，仍可沿用有效的准入授权。不支持 Bonjour 的设备可使用数字 IP 邀请。
3. **在多个标签页中打开同一邀请。** 已获准的访客可以刷新页面或重新打开有效邀请。同一浏览器的标签页共享访客身份，各自保留未发送的草稿。
4. **下载浏览器无法预览的文件。** 从附件卡片或文件链接可保存原件，包括诊断文件和无扩展名文件。

**修复**

1. **Desktop 兼容与消息投递。** 支持 Desktop 会话流协议第 13 版，修复忙碌会话中访客消息可能重复发送的问题。
2. **会话与网络选择。** 会话列表隐藏无标题会话及派生的子会话。生成内网邀请前会检查访客入口能否通过所选网络接口访问。
