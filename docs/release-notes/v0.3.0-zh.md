# Codex Co² 0.3.0 · 更多产物预览与完整会话展示

[English →](../../CHANGELOG.md#030)

**New Features**

1. **更多产物预览**：查看助手文件输出和附件中的音频、PDF、CSV/TSV、XLSX、Markdown、DOCX、PPTX，并下载原件。Office 预览显示常见文字、表格和内嵌图片，复杂内容提供降级提示。
2. **富文本渲染**：显示公式、Mermaid 图形和代码高亮，支持源码切换，预览资源随包提供。
3. **只读活动卡片**：展开 Desktop IPC 提供的工具结果、命令输出、文件变更和计划。原生审批仍由分享者处理，状态与结果以 Desktop 接口实际提供的数据为准。
4. **贴近 Desktop 的会话样式**：发送方使用黑色气泡，长消息按需展开，活动改为紧凑摘要。已完成的过程与最终回答分别展示，手动展开状态在实时更新中保留。

**Bug Fixes**

1. **会话完整性修复**：补齐从其他聊天明确投递到当前会话的用户指令，以及 Desktop 的本地历史覆盖。中途确认后的直接答复留在原位可见；快照预算优先保留变更与计划入口，并明确提示较早活动摘要的省略。修复长会话预览状态达到上限后出现空卡的问题。
2. **原生会话展示修复**：提问回复和计划确认不再暴露协议包络，保留执行中追加的用户消息，每回合只显示一个过程折叠入口。文件链接保留原标签与行内位置，文件变更按回合汇总并显示项目相对路径；原生提供时显示时间和 ChatGPT 消息来源。
