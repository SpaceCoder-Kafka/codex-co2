# Codex Co² 0.6.2

[English →](../../CHANGELOG.md#062)

- **通过 macOS 桥接插件发送截图和文件。** 访客获准加入后，可以在聊天框里粘贴截图、选择或拖入文件，单独发送或附上文字。新建共享时，支持附件的会话默认开启此功能。每条消息最多 8 个文件，单个最大 32 MiB，合计最大 64 MiB。原件保存在分享者电脑上，Agent 能否读取普通文件取决于会话的执行环境。
- **为每个共享选择是否接收附件。** 在「设置 → 消息与审批」中关闭「允许访客发送截图/附件」，该共享就只接收文字。关闭时会取消尚未传完的文件和等待提交的附件消息，已进入 Codex 队列的消息会继续处理。恢复内网共享时会沿用已保存的设置。
- **在后台唤醒会话。** 访客的文字或附件消息进入 Codex 队列后，Co² 会请求 macOS 在后台唤醒原会话。
