# Codex Co² 0.2.0 · 跨平台协作、邀请恢复与后台共享

[English →](https://github.com/SpaceCoder-Kafka/codex-co2/releases/tag/v0.2.0)

**New Features**

1. **提供更多平台的安装包**：新增 macOS 14+ 通用版及 Windows 64 位安装包、便携包，方便不同电脑协作。Windows 要求 Windows 10 1809+ 或 Windows 11，需 WebView2，暂需手动更新。
2. **申请恢复失效邀请**：原入口可访问时，经分享者批准恢复协作，减少重新索取链接。
3. **后台共享与内网恢复**：macOS 获系统允许后，退出管理界面仍可共享；内网服务重启后可保留恢复入口和待处理申请，要求原地址与端口可用。

**Chore**

1. **加强本机访问保护**：核验用户身份、文件权限和访问路径，降低越权访问风险。
