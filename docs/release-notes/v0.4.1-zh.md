# 0.4.1 更新说明

本版本候选主要调整安装包构成，保留现有协作、附件与预览能力。

- macOS 分别提供 Apple Silicon（arm64）与 Intel（x86_64）安装包，最低系统仍为 macOS 14。
- Node 和 cloudflared 继续内置。Node 使用可追溯的符号裁剪构建；安装后无需下载运行依赖。
- 网页预览资源在构建时生成，服务端只携带实际运行依赖，移除 source map、演示、测试和开发文件。Windows x64 同步裁剪依赖。
- 新 macOS 包分别使用对应架构的更新源。旧 Universal 版本需退出后手动覆盖一次对应架构应用，保留原数据目录，无需清空数据。

源码和本地候选的验证结果与已发布版本分开记录；候选构建不表示已完成 Intel、Windows 或干净机器的原生验收。
