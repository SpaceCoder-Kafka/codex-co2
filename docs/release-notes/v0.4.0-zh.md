# Codex Co² 0.4.0 · 网页发送文件与附件预览

[English →](../../CHANGELOG.md#040)

**New Features**

1. **网页发送文件**：支持选择、粘贴、拖放和仅发送附件，沿用现有准入与消息审批。每条消息最多 8 个文件，单个最大 32 MiB，合计最大 64 MiB；逐块确认后保存到主机私有目录。图片使用原生图片输入，普通文件使用 Desktop 附件引用。
2. **贴近 Desktop 的附件输入区**：附件横向排列在输入框上方。支持的图片、视频、文档和文本显示本地预览，其余格式显示图标与文件名。移除、发送或断线后释放预览资源。
3. **文档卡片与旧版 Office 下载**：常见文档附件和助手单独输出的文档显示紧凑文件卡片；DOC、XLS、PPT 支持原件下载，不支持网页预览时给出说明。

**Bug Fixes**

1. **图片附件去重**：同一张结构化图片成功展示后，隐藏重复文件卡片，保留放大与下载；图片不可预览时保留原件入口，视频卡片保持现有行为。
2. **文件展示**：文档卡片保留文件名、格式标识和链接标签，正文中的普通链接继续按原位置显示。显示标签和相同文件名不授予读取权限，也不会隐藏另一份附件。

音频理解取决于 Desktop 与模型支持。缺少主机文件转送入口的远程或云端执行环境不可用。原生 Desktop 验收仍待完成，合成协议和浏览器检查不代表已经完整对齐所有文件类型。
