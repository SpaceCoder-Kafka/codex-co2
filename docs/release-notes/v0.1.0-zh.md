# Codex Co² 0.1.0 · 浏览器协作、共享管理与应用更新

[English →](https://github.com/SpaceCoder-Kafka/codex-co2/releases/tag/v0.1.0)

**New Features**

1. **共享同一条 Codex 会话**：获准后通过浏览器协作，省去反复转发上下文。
2. **图文与附件预览**：直接查看图片、视频和文本，减少切换软件；受格式与大小限制。
3. **共享范围与有效期设置**：按需选择公网或内网、设置内网邀请期限，减少重复生成链接。
4. **协作状态提醒**：及时获知加入申请、待审批消息和任务结束；系统通知需授权。
5. **应用内更新**：查看版本并按需安装新版，省去手动找包。

**Bug Fixes**

1. **保留消息署名**：重新分享或重启后，仍能区分已识别的消息作者。
2. **补齐连接操作反馈**：显示检查与重建进度，避免重复点击。

**Chore**

1. **简化安装与校验**：提供安装包、校验文件和许可清单，减少手工配置。此版分享端要求苹果芯片及 macOS 15+。
