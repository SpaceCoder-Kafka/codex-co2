# Asset provenance

- `macos/AppIcon.png`: project-created or AI-generated artwork. The maintainer confirmed on 2026-10-21 that no third-party assets or brand marks were used. The specific creation tool and original production records have not been independently verified.
- `assets/collaboration.svg`: project-created vector illustration with synthetic names and messages, system-font fallbacks, no screenshots, live content, invitations or external resources.
- `assets/promotional_video_cn.mp4`, `assets/promotional_video_en.mp4`: maintainer-supplied Chinese and English promotional videos, embedded and linked in the corresponding README demo sections.
- On 2026-10-22, the existing `assets/promotional_video_en.mp4` was re-uploaded as a GitHub attachment to replace the English README's unavailable attachment URL. The local video file was unchanged.
- `assets/promotional_banner_cn.png`: AI-generated on 2026-10-22 using the built-in image generation tool, recomposing the maintainer-supplied Chinese poster into a 2172 × 724 (3:1) README banner while retaining its side-by-side comparison of read-only sharing and active collaboration, all four guest browser device types, and all six collaboration scenarios. The illustration contains synthetic voxel characters and devices, with no real conversations or runtime screenshots. A subsequent image-generation edit on the same date aligned the banner with the application's blue, white and cool gray palette, using the existing banner as the edit input and the CSS theme colors as prompt guidance. The Chinese README uses this banner; the original poster has been replaced in the public assets.
- `assets/promotional_banner_en.png`: AI-generated on 2026-10-22 using the built-in image generation tool to localize the Chinese banner into English, preserving its 2172 × 724 (3:1) layout, comparison, four guest browser device types and six scenarios. A subsequent image-generation edit on the same date aligned its palette with the blue Chinese edition, using the English banner as the edit target and the blue Chinese banner as a color reference. The English README uses this banner; the original English poster has been replaced in the public assets.
- On 2026-10-21, both promotional videos were reduced below 10,000,000 bytes for GitHub's free-plan video attachments. The H.264 video streams were copied without re-encoding, preserving 1920 × 1080 resolution at 30 fps; only the AAC audio was re-encoded at 48 kbit/s. The Chinese version uses the maintainer's latest source video. Original copies are retained privately. The corresponding README displays the promotional banner, embeds a GitHub-hosted video attachment in a visible demo section and retains a download link to the repository video.
- `assets/screenshot-session-picker-demo-cn.png`, `assets/screenshot-sharing-demo-cn.png`, `assets/screenshot-web-conversation-demo-cn.png`, `assets/screenshot-web-conversation-demo-cn-v2.png`, `assets/screenshot-web-debug-demo-cn.png`: maintainer-supplied Chinese demo screenshots showing conversation selection, sharing management, browser collaboration and guest help. The README galleries use the updated `v2` conversation image; the earlier variant remains available in the assets.
- `macos/InstallerArtwork.swift`: project source draws the installer artwork using macOS system fonts and the project icon. No font files are redistributed.
