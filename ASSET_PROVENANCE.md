- `assets/collaboration.svg`: project-created vector illustration with synthetic names and messages, system-font fallbacks, no screenshots, live content, invitations or external resources.
- `assets/promotional_image_cn.png`, `assets/promotional_image_en.png`, `assets/promotional_video_cn.mp4`, `assets/promotional_video_en.mp4`: maintainer-supplied Chinese and English promotional materials, displayed or linked in the corresponding README introductions.
- On 2026-10-21, both promotional videos were reduced below 10,000,000 bytes for GitHub's free-plan video attachments. The H.264 video streams were copied without re-encoding, preserving 1920 × 1080 resolution at 30 fps; only the AAC audio was re-encoded at 48 kbit/s. The Chinese version uses the maintainer's latest source video. Original copies are retained privately. The corresponding README displays the promotional poster, embeds a GitHub-hosted video attachment and retains a download link to the repository video.
- `macos/InstallerArtwork.swift`: project source draws the installer artwork using macOS system fonts and the project icon. No font files are redistributed.
